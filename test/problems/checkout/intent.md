- 第二件六折: 只在同一個 sku 之內配對. 同一個 sku 的數量 n,其中 floor(n/2) 件用六折,其餘原價. 不同 sku 的飲料不互相配對. items 裡出現相同 sku 的多個項目時,先合併數量再配對.
- 金額計算過程保留精確值 (不要每一步四捨五入),只在最後算出應付金額時四捨五入成整數一次. 四捨五入是 0.5 進位 (例如 22.5 -> 23),不是銀行家捨入.
- 計算順序: 先算商品折扣 (第二件六折),再套優惠券,最後算運費.
- SAVE100 的門檻用商品折扣後的金額判斷,剛好 1000 也算滿額 (>= 1000). 沒達門檻時優惠券無效但不報錯,照原價算.
- OFF10 是商品折扣後的金額打九折.
- 優惠券不折運費.
- 免運門檻用套用優惠券之後的金額 (未四捨五入的精確值) 判斷,>= 499 免運,否則加 60.
- 購物車是空的,或所有 qty 都是 0: 應付金額 0,不收運費.
- 不認得的優惠券代碼 (大小寫完全比對): 丟 ValueError. coupon 是 None 表示沒有優惠券.
- qty 或 price 是負數: 丟 ValueError. qty 是 0 的項目忽略.
